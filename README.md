# ArenaOOP

Учебный шаблон 2D-аркады на **Godot 4.7** и **C#**. Курс по объектно-ориентированному программированию: за 14 занятий, где вы шаг за шагом напишете законченную игру — с игроком, врагами, бонусами и таблицей рекордов.

Шаблон пока пустой: в нём есть только стартовая сцена и графика. Всю игровую логику вы создадите сами.

## Что нужно установить

| Инструмент                      | Версия           | Зачем                                                                       |
| ------------------------------- | ---------------- | --------------------------------------------------------------------------- |
| Godot Engine **.NET**           | 4.7.2 Stable     | Игровой движок. Обычная сборка не подойдёт — нужна именно с поддержкой .NET |
| .NET SDK                        | 10.x             | Компиляция C#                                                               |
| Visual Studio Code + C# Dev Kit | любая актуальная | Редактор кода                                                               |
| Git                             | любая актуальная | История изменений                                                           |

Проверьте установку в терминале:

```bash
dotnet --list-sdks
git --version
```

В списке SDK должна быть версия `10.0.x`.

## Как открыть проект

1. Скачайте шаблон и распакуйте его (или клонируйте репозиторий) в обычную папку, например `Documents/GodotProjects/ArenaOOP`.
2. Откройте Godot, в менеджере проектов нажмите **Import** и выберите файл `project.godot`.
3. В терминале из папки проекта выполните `dotnet build`. Сборка должна завершиться без ошибок.
4. Нажмите **F5**. Откроется пустое игровое окно — так и должно быть.

Если рядом с `project.godot` нет файла `ArenaOOP.csproj`, вы установили Godot без .NET.

## Правила работы

- Каждое занятие заканчивается **рабочей версией**: запустите игру и проверьте, что новая механика работает.
- Делайте **коммит** после законченного результата, а не после каждой строки. Например: `feat: add player movement`.
- Имя файла и имя класса должны **совпадать** (`Player.cs` → `class Player`).
- Не удаляйте и не переименовывайте папки `Scenes`, `Scripts`, `Assets`.
